# Análisis exploratorio de datos — Fuga y valor del cliente

**Universidad del Norte — Machine Learning · Entrega 1**

Martínez Pulido, Valerie · Basto Martínez, Abrahan · Esguerra Fernández, Rubén

Este libro presenta el **análisis exploratorio y la auditoría de calidad de datos** para
predecir la **fuga de clientes** (*churn*) y el **valor del cliente** (*CLV*) sobre el
conjunto público [COFINFAD](https://data.mendeley.com/datasets/mhb4zn3258/1) de una
empresa *fintech* colombiana (2023): 48.723 clientes con 54 variables y 3.159.157
transacciones.

En la sección siguiente se encuentran el resumen, la introducción, la metodología
(descripción del conjunto, ETL y EDA exhaustivo) y el desarrollo técnico completo con
código, tablas y figuras.
